# 桌面端的电脑使用要求交互轮次

[English](guide.md) | 中文

## 变更

在顶层桌面对话中发送提示词，就可以使用电脑控制，无需切换模式。同为 owner 的 API 客户端、定时任务、目标自动续跑和子 agent 都不能据此调用桌面 helper。已保存的应用许可和 `agentPreset: false` 不会解除这一限制。已有配置保留原有的组合包选择。

## 迁移

1. 将桌面操作从无人值守任务中分出，直接在顶层桌面对话中发送操作请求，其余后台工作保留在原任务中。
2. 在“插件”中检查“电脑使用”是否已启用，也可在此关闭。受支持的 Apple Silicon 本地构建会为新配置默认选中内置组合包。关闭后如要恢复，在“添加插件”中输入 `@deepseek-ai/dsh-cua-bundle` 并选择“启用”即可，无需重新下载。请在[电脑使用权限页面](../../../../packages/experimental/cua/README.zh.md)分别检查辅助功能、屏幕录制和应用访问许可。
